# 主观观点转可检验规则

把一段主观交易观点（评论、日报、讲话）逐条转成**可回测的交易规则**，再用人工标注样本验收抽取质量，最后对照冻结基线做成本后评估。

这个 skill 关心的是「观点能不能变成可判定的规则」，不是「观点听起来多空」。

---

## 核心问题

一段典型的主观观点长这样：

> 螺纹钢主力如果站稳 3850，未来两周有望上冲 4100，跌破 3780 则看错了。

人读完能理解，但机器没法直接检验。要真正检验它，必须先把这句话压成六个可判定字段：

| 字段 | 这句话里的值 |
|---|---|
| 标的 | 螺纹钢 → `RB`（主力连续） |
| 方向 | 多（由目标位在上方推断，并标记为推断） |
| 进场触发 | `close > 3850` |
| 期限 | 两周 = 10 个交易日 |
| 止损 | `close < 3780` |
| 止盈 | `close >= 4100` |

六个字段齐了，这句话才从「看法」变成「假设」。

## 快速开始

```bash
# 1. 抽取演示
python3 scripts/build.py

# 2. 标注样本评分（逐字段 precision / recall）
python3 scripts/annotate.py tests/fixtures/labels.json

# 3. 端到端验收（离线，用内置 CSV 行情）
python3 scripts/evaluate.py --fixture

# 4. 用 panda_data 真实行情
export PANDA_DATA_USERNAME=<你的账号>
export PANDA_DATA_PASSWORD=<你的密码>
python3 scripts/evaluate.py --panda --start 20240101 --end 20241231

# 5. 测试
python3 -m pytest tests/ -v
```

`evaluate.py` 会先把范围声明写到 `output/scope_declaration.json`（**开跑前**），跑完再把完整报告写到 `output/frozen_baseline.json`。两者都在 `.gitignore` 中。

## 设计要点

### 1. 不臆造字段

文本没说止损，`stop_loss` 就是 `null`，同时出现在 `missing_fields` 里。这样做有两个原因：标注时可以惩罚「凭空补全」，回测时也不会把作者没说的风险控制算成他的功劳。

需要补全时必须显式打开 `apply_defaults=True`，补了什么会逐条记录在 `assumed` 里，并写进 `config_hash`。

### 2. 推断必须留痕

只有价位、没有「看多/看空」字样时，可以从**目标位方向**推断多空。这种推断会写进 `ambiguity`，并在 `direction_inferred` 标记为 `true`。歧义不被隐藏，而是作为数据交给标注者判断。

### 3. 不可规则化也要输出

「明年大宗商品整体环境应该比今年好」这类句子没有标的、没有条件、没有期限。它不会消失，而是进 `unruleable` 并统计 `ruleable_share`。**如果一份来源里大部分观点都不可规则化，这本身就是有价值的结论。**

### 4. 回测不允许未来函数

只用 `published_at` 严格之后的 bar，且成交在下一根 bar 的开盘价。`published_at` 缺失时直接拒跑，不做「假设当天收盘」这类会引入前视的妥协。

### 5. 与简单基线配对比较

默认基线是**同标的、同起止日期的买入持有**。每条规则交易的收益减去同期基线收益，得到配对 edge。这样扣掉的是「那段时间行情本身」，剩下的才可能是观点带来的增量。

判定不看单笔收益高低，看：

```
≥12 笔成交 且 bootstrap CI 下界 > 0  → positive
≥12 笔成交 且 CI 上界 ≤ 0            → negative
其他                                  → inconclusive
```

**负结果是合格交付。** 如果一份来源的观点规则化后扣费也打不过买入持有，把这件事测出来、说清楚适用边界，同样是有效成果。

## 当前状态

两套样本的实测结果。注意结论的差别正是这个 skill 想暴露的东西：**同一批观点，换真实行情后结论会翻转。**

### A. 内置 fixture（离线，合成行情）

| 项 | 结果 |
|---|---|
| 抽取逐字段 exact-match | 7 个字段全部 1.00 |
| 规则产出 | 15 条（full 6 / partial 7 / neutral 2 / none 1） |
| 可规则化比例 | 0.94 |
| 回测成交 | 10 笔 |
| 配对 edge vs 持有 | −0.0032，CI [−0.0096, 0.0] |
| 判定 | `inconclusive` |

### B. panda_data 真实行情（RB / I）

| 项 | 结果 |
|---|---|
| 取数范围 | 2024-01-02 ～ 2024-12-31，242 根日线 |
| **实际成交区间** | **2024-01-09 ～ 2024-03-12**（观点只覆盖 1 月初至 2 月初，每笔按各自期限结束） |
| 抽取逐字段 exact-match | 7 个字段全部 1.00 |
| 回测成交 | 12 笔（满 12 笔门槛） |
| 规则净收益均值 | −0.0082，胜率 0.50 |
| 配对 edge vs 持有 | +0.0122，CI [−0.0045, 0.0285] |
| 判定 | `inconclusive` |

> **关于"长期检验"**：取数跨全年，但**成交只落在约 2 个月内**，因为 16 条观点集中在 2024 年 1–2 月。这不足以称为跨行情周期的长期检验，样本需要覆盖更长的时间跨度才能下这类结论。README 此处曾写作"2024 全年"，容易被误读为全年都有成交，已更正。

**怎么读这组数**：配对 edge 均值为正，但 CI 跨过 0，12 笔成交里盈亏各半。`mean net` 为负、`edge` 为正，说明这批规则自身是亏的，只是亏得比同期持有少。样本量只够到门槛，不构成"观点有效"的证据。

> **修正记录**：v0.2.0 及更早版本报告的 edge 是 `+0.0162, CI [0.0021, 0.0328]`，那个数字有缺陷——基线用了规则自己的出场日，导致**所有多头规则的 edge 恒为 0**。修复后基线改为按事先固定的期限窗口持有，上表是修正后的结果。同类问题已补回归测试。

两个数据模式下结论不同（A 的 edge 为负、B 为正），恰好说明**合成行情的结论不能当作证据**。要得到可引用的结论，需要真实的、带时间戳的单一来源观点，并把样本量做上去。

## 已知局限

- 抽取基于词典与正则，不是 LLM；**支持中文与英文（可混写）**，覆盖常见期货表述，反讽、长距离指代、生僻比喻会落到 `none` 或产生 `ambiguity`。
- 英文按词边界匹配（`long` 不命中 `longer`），但同句多空并存仍记为歧义。
- 词典是白名单，新增语言或新品种需改 `scripts/common.py`，不动逻辑。
- 品种别名是白名单，表外品种不猜。
- 组合层面的资金竞争未建模，规则逐条独立评估。
- 样本量门槛（12 笔）是按上界保守设定的，并不代表 12 笔就有统计功效。
